# CDN Access Log Explorer

A local-only dashboard for exploring and exporting Parspack CDN access logs.

## Development

Install dependencies and start the development server:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Validation

```bash
pnpm lint
pnpm build
```

This initial project setup includes Next.js App Router, TypeScript, Tailwind CSS,
ESLint, and a global TanStack React Query provider. Dashboard features and API
integration are intentionally reserved for later tasks.
